# LLM 训练的故事 — 从随机乱码到能聊天，发生了什么

> 这是新手问得最多的问题："它怎么学会的？" 这篇文章用一个故事讲清楚。

---

## 故事的起点：一堆随机数字

一个 LLM 在"出生"时，内部是几十亿个**随机数字**（参数）。

你问它："你好"，它随机输出："的饕餮皿苟盦"——完全的乱码。参数是随机的，输出必然是随机的。

**训练就是要调整这些随机数字，直到输入"你好"时，输出大概率是合理的回复。**

---

## 第一章：预训练 — 读完整个互联网

### 在哪里

几千台 GPU 组成的集群，跑 3-6 个月。

### 怎么做

把互联网上能找到的几乎所有文字（网页、书、论文、代码、维基百科...）喂给模型。几万亿个 token。

训练方法叫 **"下一个 token 预测"**——简单到难以置信：

```
给模型看："中国的首都是"  → 让它猜下一个 token
正确答案："北京"

猜对了 → 加强这条路径（这个方向调参数）
猜错了 → 反推回去，调整所有参与计算的参数（反向传播）
```

### 反向传播（重要概念，但只需要理解直觉）

```
输出："上海"（错了！应该是"北京"）

反向传播做的事：
  "错了 2.3 分。这个错误要分摊给谁？
   → 最后一层的参数负主要责任（调整大一些）
   → 倒数第二层的参数负次要责任（调整小一些）
   → ...一直追溯到第一层
   → 所有参数都调一点点，让下次输出更接近'北京'"
```

这就叫 **梯度下降**——沿着错误减少的方向，微调所有参数。

### 做完之后

模型学会了：
- 语法（"我今天去___" 后面应该填动词，不是数字）
- 事实（"中国的首都是北京"）
- 推理模式（If...then...、因为...所以...）
- 代码结构（def 后面是函数定义）
- 各种文风（新闻腔、口语腔、学术腔）

但它 **不会聊天**。你问它问题，它可能续写、可能反问、可能完全跑偏。它只知道"给定上文，下文应该是什么"。

### 成本

GPT-4 级别的预训练：大约 1-3 亿美元。这是为什么只有少数公司能做出基础模型。

## 第二章：SFT — 教它"对话的格式"

### 在哪里

几十张 GPU，跑几小时到几天。

### 怎么做

收集几万到几十万条"理想对话"：

```json
{
  "messages": [
    {"role": "user", "content": "什么是 Transformer？"},
    {"role": "assistant", "content": "Transformer 是一种..."}
  ]
}
```

让模型看这些问题和回答，继续做"下一个 token 预测"——只是这次的数据全都是一问一答的格式。

### 做完之后

模型学会了两件事：
1. **对话格式：** 用户说话 → 我回答。不是续写、不是反问。
2. **指令遵循：** "解释 X" → 我应该用解释的口吻回答，不是列一堆事实。

### 和预训练的关键区别

| | 预训练 | SFT |
|---|---|---|
| 数据 | 整个互联网（几万亿 token） | 人工标注的对话（几万条） |
| 目标 | 学会语言本身 | 学会对话格式 |
| 成本 | 几亿美元 | 几千到几万美元 |
| 产出 | Base Model（会续写） | Instruct Model（会聊天） |

### 你做过的事

Phase 4 的 LoRA 微调，**本质上就是一次极小的 SFT**——200 条数据、一张显卡、几分钟、几块钱。只是你教的是"回答要简洁"，而不是"学会对话格式"。

## 第三章：RLHF — 教它"什么是对的"

### 为什么还需要这一步

SFT 之后的模型已经会聊天了，但不知道什么回答是"好"的。

你问："怎么做一个炸弹？"

模型可能的回答：
- A："你需要硝酸铵、雷管..."（危险）
- B："我不能帮你制作武器。如果你对化学感兴趣，可以学..."（安全）

两个回答都符合"对话格式"，但只有 B 是"好"的回答。

### 怎么做

1. 让模型对同一个问题生成多个回答（A、B、C、D）
2. 人类标注者排序：B > D > C > A
3. 训练一个"奖励模型"：学会预测人类会给什么回答高分
4. 用奖励模型来进一步微调 LLM：让它倾向输出高分回答

### 三个标准

| 标准 | 什么意思 | 例子 |
|------|---------|------|
| **有用 Helpful** | 真正解决了用户的问题 | 要代码给代码，要解释给解释 |
| **无害 Harmless** | 不生成危险、歧视、违法内容 | 拒绝教做炸弹，拒绝种族歧视 |
| **诚实 Honest** | 不知道就说不知道 | "抱歉，我的训练数据截止到..." |

## 你的 LoRA 微调在哪一层

LoRA 微调发生在 **SFT 那一层**。你在一个已经预训练好的模型上，用自己的数据做了一次小规模的 SFT。

```
别人的预训练（几万亿 token）→ 你不能重做
    ↓
你的 LoRA 微调（200 条数据）→ 这就是你的 SFT
    ↓
（你没有做 RLHF——也不需要，200 条数据不需要对齐）
```

## 常见困惑

### "模型在训练时真的'理解'了知识吗？"

不。它学到的是"统计规律"——给定上文，下文大概率是什么。它不知道"北京是中国的首都"这个事实——它只知道"中国的首都是"后面接"北京"的概率非常高。

这和人类的知识存储完全不同。人类有概念、有因果、有体验。模型只有概率。

### "训练和推理有什么区别？"

| | 训练 | 推理 |
|---|---|---|
| 在做什么 | 调整参数 | 只使用参数，不调整 |
| 数据流 | 输入 → 计算 → 输出 → 对比答案 → 反向传播调整参数 | 输入 → 计算 → 输出（结束） |
| 硬件 | 需要大量 GPU，做正反两遍计算 | 只需跑一遍计算 |
| 成本 | 极高 | 相对低 |

**你在 CLI 客户端里的每次对话，模型都在做"推理"——参数不变，只计算。**

### "为什么训练贵但推理相对便宜？"

训练要做两遍（正向+反向），推理只做一遍（正向）。而且训练需要存中间结果（梯度），显存需求更大。

类比：写一本书（训练）需要几年，但印刷一本书（推理）只需要几秒钟。

---

## 一句话总结

> 预训练 = 读完全网，学会"语言"。SFT = 学会"对话"。RLHF = 学会"什么是对的"。你做的 LoRA 微调，就是一个极小的 SFT。
